# 소비 기록 및 지출 분석 프로그램(MoneyLog)
MoneyLog

1. 프로젝트 소개

MoneyLog는 사용자가 자신의 소비 내역을 기록하고 총 지출 및 소비 항목을 확인할 수 있는 소비 관리 프로그램입니다.

2. 프로젝트 목적

일상생활에서 발생하는 지출을 간단하게 기록하고, 자신의 소비 패턴을 파악할 수 있도록 돕는 것을 목표로 합니다.

3. 주요 기능

- 소비 금액 입력
- 소비 카테고리 선택
- 지출 날짜 입력
- 소비 내역 확인
- 총 지출 계산

4. 개발 환경

- HTML
- CSS
- JavaScript
- GitHub
