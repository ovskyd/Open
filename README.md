# MoneyLog 최종 제출본

## 프로젝트 소개
MoneyLog는 사용자가 일상 지출을 기록하고, 월별 예산과 소비 패턴을 확인할 수 있는 브라우저 기반 소비 관리 웹 앱입니다. HTML, CSS, JavaScript만 사용하며 별도 설치나 서버 없이 실행합니다.

## 주요 기능
- 지출 등록: 금액, 카테고리, 날짜, 메모 입력 및 사용자 카테고리 추가
- 내역 관리: 월별 조회, 카테고리 필터, 검색(메모·카테고리·금액·날짜), 정렬, 수정, 삭제
- 홈 요약: 오늘 지출, 하루 평균, 월 지출, 예산 잔액, 최다 지출 카테고리, 전월 비교
- 예산 관리: 월별 예산 및 사용률 표시, 임계/초과 표시
- 분석: 카테고리별 지출 및 최근 3개월 추세
- 백업: JSON 백업·복원, CSV 내보내기, 복원 데이터 검증 및 중복 방지
- 발표 지원: 시연용 예시 데이터 추가 버튼
- 저장: 브라우저 LocalStorage

## 실행 방법
1. `index.html` 파일을 다운로드합니다.
2. Chrome, Edge 등 브라우저에서 파일을 엽니다.
3. 발표 시 `관리` 탭의 **시연용 예시 데이터 추가** 버튼으로 화면에 데이터를 채울 수 있습니다.

## 데이터 관련 주의
데이터는 실행한 브라우저의 LocalStorage에 저장됩니다. 다른 컴퓨터나 브라우저와 자동 동기화되지 않습니다. 제출 또는 발표 전에 JSON 백업을 권장합니다. 예시 데이터는 실제 소비 데이터가 아닙니다.

## 발표 시연 순서(권장)
1. 홈에서 월별 요약과 예산 사용률 확인
2. 기록 탭에서 지출 한 건 입력
3. 내역 탭에서 검색·정렬·수정·삭제 확인
4. 분석 탭에서 카테고리와 3개월 추세 확인
5. 관리 탭에서 CSV/JSON 백업 기능 설명

## 기술
- HTML: 화면과 입력 구조
- CSS: 반응형 레이아웃 및 스타일
- JavaScript: 지출 데이터 처리, 분석, 차트, 저장 및 백업
- 저장소: LocalStorage
